# Story Hub

Story Hub هو مشروع ويب احترافي يدمج:
- صفحة رئيسية جذابة
- نظام تسجيل دخول وإنشاء حساب
- نظام الألعاب والتحديثات
- نظام الأخبار
- مساعد ذكي

## التشغيل محليًا

1. افتح المجلد في المتصفح مباشرةً أو استخدم خادم محلي بسيط.
2. افتح ملف index.html.

## النشر على GitHub Pages

1. ارفع المشروع إلى GitHub.
2. افتح الإعدادات → Pages.
3. اختر مصدر GitHub Actions أو الفرع الرئيسي.
4. سيتم نشر المشروع على:
   https://isshakchakkour-art.github.io/Iss-gems-/

## هيكل المشروع

- index.html: الصفحة الرئيسية
- style.css: التصميم الرئيسي
- interface.css: واجهة الحساب والبطاقات
- buttons.js: التنقل والأزرار
- auth.js: تسجيل الدخول والتسجيل
- database.js: تكوين Firebase
- games.js: نظام الألعاب
- news.js: نظام الأخبار
- ai-assistant.js: المساعد الذكي
